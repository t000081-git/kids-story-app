# Kids Story App

A personalized bedtime story generator for kids. Enter a name, pick a theme, choose a length, and the app writes a gentle, age-appropriate story you can read together page-by-page.

**Live demo:** https://kids-story-app-green.vercel.app

## What it does

- Asks for the child's **name**, a **theme** (animals, dinosaurs, dragons & dungeons, magic — or your own custom theme), and a **length** (short = 2 pages, medium = 4, long = 6).
- Calls **OpenRouter** (`openai/gpt-oss-120b:free`) to write a warm, kid-safe story starring that child and theme.
- Renders the story page-by-page with Previous / Next navigation and a **▶ Read to me** button that uses the browser's Web Speech API (prefers high-quality voices like Premium / Enhanced / Google / Microsoft).
- Each page shows a soft watercolor illustration. In local dev, illustrations are generated by Pollinations.ai through a server-side proxy (`/api/illustration`). On the deployed site, Pollinations blocks Vercel's outbound IPs, so the app falls back to a themed gradient + emoji card.

## Tech stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4. Lora serif font from `next/font/google`. In-memory rate limit of 5 stories per IP per hour. No paid API tiers — the model gate refuses to start unless the model name ends in `:free`.

## Local setup

```bash
git clone git@github.com:t000081-git/kids-story-app.git
cd kids-story-app
npm install
cp .env.example .env.local
# Edit .env.local and paste your key:
#   OPENROUTER_API_KEY=sk-or-v1-...
npm run dev
```

Open http://localhost:3000 (or 3001 if 3000 is taken).

## Environment variables

| Var | Required | Notes |
|---|---|---|
| `OPENROUTER_API_KEY` | yes | Free-tier key from https://openrouter.ai/keys |
| `LUMENPRO_API_KEY` | no | Reserved. LumenPro had no public REST API at the time of writing, so image generation uses Pollinations.ai instead. |

## Project layout

```
app/
  api/
    generate-story/route.ts   # OpenRouter call, validation, rate limit
    illustration/route.ts     # Pollinations.ai proxy (server-side)
  components/
    StoryApp.tsx              # state container
    StoryForm.tsx             # name + theme + length inputs
    StoryView.tsx             # paginated view + Read-to-me + illustration
  globals.css                 # cream/brown palette + Lora font wiring
  layout.tsx
  page.tsx
lib/
  rate-limit.ts               # 5 stories per IP per hour, in-memory
```

## Notes for future iteration

- **Pollinations on Vercel:** swap to a service that doesn't block serverless IPs (Hugging Face Inference API, Replicate, Together.ai) to restore real illustrations on the deployed site.
- **Voice quality:** the picker prefers Premium / Enhanced / Neural / Google / Microsoft voices. On Safari/macOS, install Premium voices via System Settings → Accessibility → Spoken Content → System Voice for the best result.
- **Rate limit** is in-memory and resets on serverless cold start. For real production use, move to Vercel KV / Upstash Redis.
