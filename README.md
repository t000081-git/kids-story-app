# Kids Story App

A personalized bedtime story generator for children. Enter a name, pick a theme, and get a gentle age-appropriate story that reads itself aloud — complete with illustrations, background lullaby music, and a night-sky that fills with stars for every story you save.

**Live demo:** https://kids-story-app-green.vercel.app

---

## Features

### Story generation
- Enter the **child's name**, choose a **theme** (animals, dinosaurs, space, magic, and many more via a scrollable carousel), and pick a **length** (short = 2 pages, medium = 4, long = 6).
- Stories are generated by **OpenRouter** (`openai/gpt-oss-120b:free`) — always on the free tier; a safety guard in the API route refuses to run any non-`:free` model.
- **Multilingual** — stories and narration available in English 🇬🇧, Arabic 🇸🇦, and Tagalog 🇵🇭.

### Reading experience
- Paginated storybook view with ← Previous / Next → navigation.
- Soft watercolor-style **illustrations** on every page (Pollinations.ai via a server-side proxy).
- **▶ Read to me** — narrates the current page using ElevenLabs TTS with **karaoke-style word highlighting** (each word lights up as it is spoken). Falls back to the browser's Web Speech API when ElevenLabs is unavailable.
- Voice is automatically matched to the story's theme and language (adventure themes → deep male narrator, calm themes → gentle female voice, Arabic → Grandma Arabic voice).
- **Auto-narration** mode advances pages automatically after each one finishes reading.
- **🎵 Lullaby music** — five distinct Web Audio API melodies (Kalimba, Sparkle, Adventure, Nature, Haunted) played in the background while narrating. The melody is auto-selected to match the story theme — no user choice needed.
- Auto-scroll keeps the highlighted word visible in the text container during narration.

### Night sky & saving
- An animated night sky (stars, comets, moon) surrounds the content card.
- **⭐ Save locally** — saves the story to `localStorage`; the star appears in the night sky as a twinkling gold star. Size reflects the rating (1–5 stars).
- **🌌 Save to cloud** — one-click permanent share link backed by Vercel KV. The local star transforms into a spinning galaxy orb. The share URL is copied to clipboard automatically.
- Saved stories appear in the night sky as interactive icons — hover for a tooltip (title, rating, date, browser/OS), click to re-read, or delete via the confirmation dialog in the tooltip.
- On save, a toast pill slides up, flies across the screen to the exact star position, and explodes in a poof animation — revealing the newborn star at that spot.
- Permanent share links (`/story/[id]`) are fully shareable — anyone with the link can read the story.
- **Auto-narration off by default** on saved/replayed stories (so it doesn't immediately start reading when someone opens a share link).

## Tech stack

| Layer | Technology |
|---|---|
| Framework | Next.js 16 (App Router), React 19, TypeScript |
| Styling | Tailwind CSS 4, Framer Motion |
| Font | Lora (Google Fonts via `next/font/google`) |
| Story AI | OpenRouter — `openai/gpt-oss-120b:free` |
| Narration | ElevenLabs TTS → Web Speech API fallback |
| Illustrations | Pollinations.ai (server-side proxy) |
| Cloud saves | Vercel KV (Upstash Redis) |
| Music | Web Audio API (all melodies synthesised in-browser, no files) |
| Deployment | Vercel |

## Local setup

```bash
git clone git@github.com:t000081-git/kids-story-app.git
cd kids-story-app
npm install
cp .env.example .env.local
# Fill in your keys (see table below)
npm run dev
```

Open http://localhost:3000 (or 3001 if 3000 is taken).

The app runs without `ELEVENLABS_API_KEY` and without KV credentials — it falls back to the browser's Web Speech API for narration, and cloud-save is disabled gracefully.

---

## Environment variables

| Variable | Required | Notes |
|---|---|---|
| `OPENROUTER_API_KEY` | **Yes** | Free key from https://openrouter.ai/keys |
| `ELEVENLABS_API_KEY` | No | Free tier works. Without it, narration uses Web Speech API. |
| `KV_REST_API_URL` | No | Injected automatically by Vercel KV add-on. Needed for cloud saves / share links. |
| `KV_REST_API_TOKEN` | No | Same — injected by Vercel KV. |
| `LUMENPRO_API_KEY` | No | Reserved. LumenPro had no public REST API at build time; not used. |

## Project layout

```
app/
  api/
    generate-story/route.ts   # OpenRouter call, input validation, rate limiting
    illustration/route.ts     # Pollinations.ai proxy (avoids CORS + IP blocks)
    narrate/route.ts          # ElevenLabs TTS — picks voice from theme/language
    stories/route.ts          # Vercel KV: save story, return share URL
  components/
    StoryApp.tsx              # Top-level state container
    StoryForm.tsx             # Name + theme carousel + length + language inputs
    StoryView.tsx             # Paginated reader: narration, karaoke, save, toast
    NightSky.tsx              # Animated background (stars, moon, comets)
    NightSounds.tsx           # Ambient audio (night crickets etc.)
    SavedStoryStars.tsx       # Renders saved stories as interactive sky icons
    ThemeCarousel.tsx         # Vertically scrolling theme picker
  story/
    [id]/                     # Permanent share-link page (server-rendered)
  globals.css                 # Animations + custom classes (twinkle, galaxy, poof…)
  layout.tsx
  page.tsx
lib/
  audio-cache.ts              # In-memory cache for ElevenLabs audio per page
  lullaby-melody.ts           # Five Web Audio melodies + theme → style mapping
  rate-limit.ts               # 5 stories per IP per hour, in-memory
  saved-stories.ts            # localStorage helpers for local saves
  story-kv.ts                 # Vercel KV read/write helpers
```

## Notes

- **Illustrations on Vercel:** Pollinations.ai blocks Vercel's outbound IPs, so illustrations fall back to a themed gradient + emoji card on the deployed site. Swap the `/api/illustration` route to Hugging Face Inference API or Replicate to restore real images in production.
- **Voice quality:** Web Speech API prefers Premium / Enhanced / Google / Microsoft voices. On macOS/Safari, install Premium voices via System Settings → Accessibility → Spoken Content → System Voice for the best result.
- **Rate limit** is in-memory and resets on cold start. For real production use, move to the Vercel KV instance already used for story saves.
- **Cloud saves** require the Vercel KV add-on to be attached to the project. Without it, the "Save to cloud" button is hidden — local saves still work.
